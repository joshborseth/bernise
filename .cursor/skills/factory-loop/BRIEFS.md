# Factory comments

Every comment posted to Linear during a factory run starts with:

```
> *This was generated by AI during factory-loop.*
```

## Agent Brief

Posted when moving to `ready-for-agent` or `ready-for-human`. Durable: interfaces and behaviour, never file paths or line numbers. The brief is the contract an implement run will use.

```markdown
> _This was generated by AI during factory-loop._

## Agent Brief

**Category:** bug / enhancement
**Summary:** one-line description of what needs to happen

**Current behavior:**
What happens now.

**Desired behavior:**
What should happen after the work, including edge cases.

**Key interfaces:**

- Type or function: what must change and why (no paths, no line numbers)

**Acceptance criteria:**

- [ ] Independently verifiable criterion
- [ ] Independently verifiable criterion

**Out of scope:**

- Adjacent work this issue must not absorb

**Why human (ready-for-human only):**

- The judgment, secret, or manual step an AFK agent cannot take
```

## Triage Notes (`needs-info`)

```markdown
> _This was generated by AI during factory-loop._

## Triage Notes

**What we've established so far:**

- point 1
- point 2

**What we still need from you:**

- specific, actionable question 1
- specific, actionable question 2
```

## Already implemented (`wontfix`)

```markdown
> _This was generated by AI during factory-loop._

## Already implemented

This behaviour already exists: <name the interface / command / user-visible path>.

Closing as wontfix for that reason. Not a rejection of the idea.
```

## Blocked

```markdown
> _This was generated by AI during factory-loop._

Ready for an agent but blocked on <identifiers>. Implement starts when those are Done or Canceled.
```
